## 🚀 What I Do

### 🔹 Backend Engineering (.NET)
- Design and deploy backend services with **ASP.NET Core Web API**, **EF Core** and **SQL Server** (.NET 6 / 7 / 8 / 9)
- Apply **Clean Architecture**, **Repository & Unit of Work**, and design patterns for maintainable, modular code
- Build REST APIs for web and mobile clients, documented with **Swagger / OpenAPI**
- Secure APIs with **JWT authentication**, role-based access, and custom middleware for exception handling and logging
- Optimize query performance and add caching (**MemoryCache, Redis**) for large-scale workloads
- Add real-time features with **SignalR**, and structured logging with **Serilog / NLog**

### 🔹 Mobile & Full-Stack Delivery
- Ship cross-platform apps with **Flutter** (BLoC, Provider, GoRouter, Hive) integrated with REST APIs and **Firebase**
- Deliver e-commerce, booking, and ERP-style systems with secure login, payment gateways, and reporting
- Own the full lifecycle with **Git, Agile, CI/CD**: GitHub Actions and Azure DevOps pipelines, code reviews, and junior mentoring

### 🔹 Technical Training
- Delivered intensive training on **.NET Core, Entity Framework, RESTful APIs, and software architecture patterns**
- Guided trainees from zero to full-stack projects with **ASP.NET Core + Flutter**
